# TermoBox — основа прайсу для ROZETKA

Дата: 08.11.2026. Ціни та комплектацію надано засновницею в поточній розмові. Валюта: гривня. Це погоджені вхідні дані для підготовки каталогу, а не опублікований XML-фід.

## Товари та ціни

| Модель | Ціна комплекту, грн | Корпус | Контейнери для їжі | Нагрівачі у комплекті |
|---|---:|---|---|---:|
| TermoBox GO | 2 390 | Харчовий силікон | 1 контейнер 680 мл з герметичною кришкою | 3 шт. |
| TermoBox CHEESE | 2 390 | Харчовий силікон | 1 контейнер 680 мл з герметичною кришкою | 3 шт. |
| TermoBox HOME | 3 990 | Харчовий силікон | 3 контейнери: 680 мл, 1 200 мл і 150 мл, з герметичними кришками | 3 шт. на весь комплект |

Для HOME записано саме 150 мл — як у повідомленні засновниці. Потрібно уточнити, чи це остаточне значення, а також чи три ємності використовують одночасно або обирають одну для підігріву.

## Пропоновані постійні ідентифікатори

| Модель | ID для майбутнього XML | Пропонований артикул |
|---|---|---|
| GO | TBXGO001 | TBX-GO-001 |
| CHEESE | TBXCHEESE001 | TBX-CHEESE-001 |
| HOME | TBXHOME001 | TBX-HOME-001 |

Ці ID та артикули запропоновано для першого каталогу; їх ще не завантажено на ROZETKA. Після підключення ID залишаємо сталими, ціну змінюємо у відповідному товарі.

## Чернетки назв і описів

### GO

Назва: Бокс для автономного підігріву їжі TermoBox GO 680 мл з трьома нагрівачами

Багаторазовий бокс для автономного підігріву готової їжі без електроенергії та відкритого полум’я. Нагрівальний елемент активується водою. Комплект містить корпус із харчового силікону, контейнер для їжі об’ємом 680 мл із герметичною кришкою та три нагрівачі. Використовуйте відповідно до інструкції виробника.

### CHEESE

Назва: Бокс для автономного підігріву їжі TermoBox CHEESE 680 мл з трьома нагрівачами

Багаторазовий бокс для автономного підігріву готової їжі без електроенергії та відкритого полум’я. Нагрівальний елемент активується водою. Комплект містить корпус із харчового силікону, контейнер для їжі об’ємом 680 мл із герметичною кришкою та три нагрівачі. Використовуйте відповідно до інструкції виробника.

Опис CHEESE попередній: потрібно додати підтверджену відмінність від GO. Окреме призначення для приготування або плавлення сиру не заявлено.

### HOME

Назва: Набір для автономного підігріву їжі TermoBox HOME з трьома контейнерами та трьома нагрівачами

Багаторазовий набір для автономного підігріву готової їжі без електроенергії та відкритого полум’я. Нагрівальний елемент активується водою. Комплект містить корпус із харчового силікону, три контейнери для їжі об’ємом 680 мл, 1 200 мл і 150 мл із герметичними кришками та три нагрівачі. Використовуйте відповідно до інструкції виробника.

## Що потрібно для готового XML-фіду

- Фото кожної моделі та доступні HTTPS-посилання на ці фото.
- Підтверджена наявність і фактична кількість комплектів для продажу.
- Підтверджені відмінності моделей GO та CHEESE.
- Уточнення найменшого об’єму HOME і способу використання контейнерів.
- Вибір відповідної категорії ROZETKA та заповнення її обов’язкових характеристик.
- Постійна публічна URL-адреса готового XML-файлу.

Орієнтир «одна людина / дві людини / маленька сім’я» поки не додано до покупецьких описів: об’єми самі по собі не визначають кількість порцій.
